# 성능 (NFR-01)

측정일 2026-10-18, 릴리스 빌드, 이 개발 PC(Windows 11). 값은 중앙값이고 기기마다 다르다. 회귀를 잡는 용도로 같은 기기에서 비교한다.

## 벤치마크 (`cargo bench -p ldf-engine`)

합성 LDF(슬레이브 20개, 프레임마다 시그널 4개, 스케줄 하나)를 쓴다.

| 항목 | 입력 | 시간 | 기준 |
| --- | --- | --- | --- |
| 분석(디코딩 → 파싱 → lowering → 전체 검사) | 107 KB | 11.4 ms | 임포트+전체 검사 1초 이내 |
| 분석 | 1,042 KB | 223 ms | 〃 |
| 임포트(분석 + SQLite 저장, 메모리 DB) | 107 KB | 50 ms | 〃 |
| 편집 → 쓰기 → 다시 읽기 → 전체 재검사 | 107 KB | 24.6 ms | FR-CHK-09: 200 ms 이내 |
| 모델 → LDF 텍스트 | 107 KB | 2.2 ms | — |

## 화면·메모리·시작 (수동 측정)

| 항목 | 결과 | 기준 |
| --- | --- | --- |
| UI 프레임(5,000프레임·10,000시그널 파일) | 1.1 ms/프레임 | 16 ms 이내 |
| 콜드 스타트(창이 뜰 때까지) | 0.4–0.8 s | 2 s 이내 |
| 1 MB LDF를 연 뒤 작업 집합 | glow 207 MB, wgpu(대체 경로) 455 MB | 300 MB 이하 |
| 시그널 500개 LDF에서 편집 → 재검사(통합 시험) | 3.5 ms | 200 ms 이내 |

UI 프레임은 `LDF_STUDIO_PERF=1`로 상태 바에서 읽고, 메모리는 `Process.WorkingSet64`로 쟀다.
